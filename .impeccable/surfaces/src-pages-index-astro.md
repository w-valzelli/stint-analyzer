# Analyzer surface brief

- **Mode:** Operate
- **Audience:** Drivers and coaches in a post-session debrief.
- **Job:** Compare selected drivers and stints, understand the runtime gap, and trace important numbers to source laps.
- **First proof:** The first screen shows an immediate comparison as soon as local files are ready.
- **Constraints:** Preserve local-only analysis, clear scope controls, separate runtime from pace, manual penalty entry, and lap-level auditability. Avoid motorsport costume and decorative performance theater.
- **Chosen direction:** Calibration Ledger. Use industrial calibration sheets and transparent drafting overlays as a functional visual system. Make comparison read as a measured instrument, not a generic dashboard.
- **Memorable moment:** A user selects a headline runtime gap and sees the supporting laps register beneath it without losing the comparison.
- **Unresolved decisions:** Data-rich analysis states and the import workflow remain open until later milestones. The visual language, type pairing, and responsive breakpoints are established in the built shell and `DESIGN.md`.
